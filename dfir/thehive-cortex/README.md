# TheHive + Cortex

TheHive for incident management, Cortex for automated IOC enrichment. Cortex analyzers automatically enrich cases with VirusTotal lookups, WHOIS, and GeoIP data when an alert comes in.

- TheHive: 10.10.10.22:9000
- Cortex: connected to TheHive, runs analyzers on indicators
